# Synergy Squad — Website Redesign

> A UI/UX redesign and frontend development project for Synergy Squad, a technical training and placement-focused club at my college.

## Overview

Synergy Squad is a technical training and new-initiative club at my college focused on helping students improve their technical skills and prepare for placement opportunities.

This project involves redesigning the existing Synergy Squad website with a stronger focus on:

- User experience
- Visual hierarchy
- Modern interface design
- Responsive layouts
- Clear content presentation
- Accessibility
- Consistent design language

The goal is to transform the existing website into a more engaging, intuitive, and professional digital experience for students.

> **Status: Ongoing**

##  Project Goals

The redesign aims to:

- Improve the overall user experience
- Create a modern and consistent visual identity
- Make important information easier to discover
- Improve navigation and content hierarchy
- Design responsive experiences across devices
- Present the club's activities, initiatives, members, and achievements effectively
- Create a scalable design system for future updates
